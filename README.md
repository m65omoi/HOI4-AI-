HOI4 AI自动翻译助手

注意:该应用程序未做好对分辨率的适配，需要放大化即可看到开始翻译按钮
必须安装Python


所有翻译使用本地大语言模型完成，完全离线、无需联网、无需API、永久免费。

核心功能
必装核心库:pip install transformers accelerate bitsandbytes sentencepiece
智能硬件检测 - 自动识别你的显卡和内存，推荐最适合的模型并一键下载
完美兼容Paradox格式 - 正确保留§Y颜色代码§!、[GetVariable]变量、\n换行符
批量翻译整个模组 - 选择localisation文件夹，自动扫描所有YML文件
断点续传 - 翻译中断后下次继续，不会重复劳动
术语表管理 - 自定义国名、人名、专有名词翻译，保持全文一致性
自动启动Ollama - 无需手动配置，程序自动管理后台服务
图形化界面 - 简洁易用，新手也能轻松上手
翻译完成自动打开文件夹 - 一键定位输出文件

支持语言（11种互译）
英语、简体中文、繁体中文、日语、韩语、俄语、德语、法语、西班牙语、葡萄牙语、波兰语

开始
下载并安装 Ollama[ollama.com]（只需安装一次）
解压本工具，双击运行 启动.bat
首次启动会自动检测硬件，点击下载推荐模型
选择要翻译的文件或文件夹：
单文件：选择 xxx_l_english.yml 文件
整个模组：选择模组根目录或 localisation 文件夹
选择源语言 → 目标语言（默认：英语→简体中文）
点击开始翻译，等待完成即可！

翻译好的文件会输出到 output/simp_chinese/ 目录，复制到模组对应位置即可使用。

系统要求
配置	推荐模型	预计速度
8GB+ 显存 (NVIDIA)	7B 模型 (qwen2.5:7b)	快速
16GB+ 显存	14B 模型 (qwen2.5:14b)	高质量
无独显 / 8-16GB 内存	小模型 / CPU运行	较慢但可用

注意事项
首次使用需要下载AI模型（约4GB），请耐心等待
翻译速度取决于硬件，GPU很快，纯CPU会慢一些
AI翻译仅供参考，建议对关键内容（国家焦点、事件选项）进行人工校对
本工具不会修改你的原始模组文件，只生成新的翻译文件
